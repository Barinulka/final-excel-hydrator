# 03. Редактор модели и вкладки

## Цель

Сделать страницу редактирования финансовой модели как набор вкладок.

Вкладки нужны, чтобы модель развивалась по блокам, а не превращалась в один большой экран.

## Основной route

```text
GET /projects/{projectShortId}/models/{financialModelShortId}/edit/{tabKey}
```

Route name:

```text
app_financial_model_edit
```

Старый route временных параметров:

```text
GET /projects/{projectShortId}/models/{financialModelShortId}/time-params
```

оставлен как compatibility redirect на:

```text
/edit/input_params
```

## Принятые решения

- Список вкладок не хранится в Twig вручную.
- Каждая вкладка регистрируется через provider.
- Layout страницы общий для всех вкладок.
- Активная вкладка определяется через `tabKey`.
- Пока большинство вкладок являются placeholder.
- Вкладка `Расчеты` уже подключена к preview API и выводит `CalculationResult`.

## UI-правила

- Страница редактора показывает общую сводку модели над содержимым вкладки.
- Вкладка `Входные параметры` содержит модальное редактирование TimeParams.
- Вкладка `Расчеты` не дублирует сводку сверху.
- В таблицах расчетов заголовки периодов выводятся номерами `1`, `2`, `3`, ...
- Даты периода выводятся отдельными строками `Начало месяца` и `Окончание месяца`.

## Критерии готовности

- Все вкладки открываются по единому route.
- Старый route `/time-params` не ломает пользователей и делает redirect.
- Controller страницы не содержит бизнес-логики вкладок.
- Новый блок можно добавить через новый provider и Twig template.
